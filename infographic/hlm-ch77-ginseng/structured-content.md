# 第77回的百年人参

## Overview

《红楼梦》第七十七回开篇，王夫人为病中的王熙凤配药，遍寻二两上等人参；贾母取出"当日所余"的一大包，医生却说它"年代太陈"、"朽糟烂木，也无性力的了"。一根百年人参，成为贾府由盛转衰最凝练的物象。

## Learning Objectives

The viewer will understand:
1. 人参事件的来龙去脉：谁要、找谁、结果如何。
2. "百年人参"象征贾府祖业——外表上好，内里无性力。
3. 由物及人、由家及国的解读层次（属读者诠释，非作者明示）。

## Section 1: 寻参

**Key Concept**: 一场遍寻不得的尴尬——全府凑不出二两能用的上等人参。

**Content**:
- 王熙凤病，需"上等人参二两"配调经养荣丸。
- 王夫人翻寻半日，只找到几枝"簪挺粗细"的细参、一大包须末。
- 问凤姐，只有些"参膏芦须"；问邢夫人，"早已用完了"。
- 贾母命鸳鸯取出"当日所余"，"竟还有一大包，皆有手指头粗细的"。
- 医生回："固然是上好的……但年代太陈了……只过一百年后，便自己就成了灰了。如今这个虽未成灰，然已成了朽糟烂木，也无性力的了。"
- 王夫人"低头不语，半日"，只好去买，并嘱咐瞒着贾母。

**Visual Element**:
- Type: icon / small scene
- Subject: 药匣、参枝、药碗
- Treatment: 简洁线描，旁注引文

**Text Labels**:
- Headline: "一、寻参"
- Labels: "上等人参二两", "簪挺粗细", "一大包手指头粗细", "朽糟烂木，无性力"

## Section 2: 物象

**Key Concept**: 百年人参＝贾府的祖业——架子还在，气数尽了。

**Content**:
- "一大包手指头粗细"＝表面的排场；"朽糟烂木，也无性力的了"＝内里的实况。
- 第二回冷子兴："百足之虫，死而不僵"／"如今的儿孙，竟一代不如一代了"。
- 第七十二回：贾琏求鸳鸯借当；凤姐押金项圈；林之孝议裁减人口月钱。
- "瞒着贾母"：旧时代的体面还在，只是要瞒着旧时代的人来维持。

**Visual Element**:
- Type: split illustration / specimen
- Subject: 一根人参，左半边饱满鲜亮，右半边枯朽成灰
- Treatment: 标本图式，左右对照

**Text Labels**:
- Headline: "二、物象"
- Labels: "表面：一大包上好", "内里：朽糟烂木", "百足之虫，死而不僵"

## Section 3: 四个人物

**Key Concept**: 一根人参照出四种处境。

**Content**:
- 王熙凤——被药吊着的人：行经之后"沥沥淅淅的没有止住"，鸳鸯说"这可不成了血山崩了"。
- 贾母——旧时代的最后持有者：她的参是"当日所余"，"固然是上好的"，却"年代太陈"。
- 王夫人——维持者：寻参、决定去买、叮嘱瞒着老太太。
- 薛宝钗——外来者与新兴商业力量：薛家皇商，能从参行兑"未作的原枝好参"。

**Visual Element**:
- Type: four small portraits around a ginseng
- Subject: 凤姐、贾母、王夫人、宝钗
- Treatment: 古风小像，各配一句关键词

**Text Labels**:

- Labels: "王熙凤：被药吊着", "贾母：最后的持有者", "王夫人：维持者", "薛宝钗：新兴商业"

## Section 4: 真假

**Key Concept**: 市面的假参能卖，府里的真参已朽。

**Content**:
- 宝钗："外头卖的人参都没好的……必截做两三段，镶嵌上芦泡须枝，掺匀了好卖。"
- 第一回对联："假作真时真亦假，无为有处有还无。"
- 真者已朽，假者横行。

**Visual Element**:
- Type: binary comparison
- Subject: 拼接的假参 vs 朽坏的真参
- Treatment: 左右对照，真假标签

**Text Labels**:
- Headline: "四、真假"
- Labels: "假参：截做两三段", "真参：已无性力", "假作真时真亦假"

## Section 5: 由家及国（读者诠释）

**Key Concept**: 把"一家之败"读成"一个时代之变"——这是读者的诠释，不是作者明示。

**Content**:
- 原著自设边界：第一回"无朝代年纪可考""将真事隐去"。
- 索隐派·蔡元培《石头记索隐》（1917）："《石头记》者，清康熙朝政治小说也……在吊明之亡，揭清之失。"
- 自传/考证派·胡适《红楼梦考证》（1921）："《红楼梦》这部书是曹雪芹的自叙传。"
- 两派方向一致：家国同构。"百年"恰是一个王朝由盛转衰的尺度。

**Visual Element**:
- Type: layered / concentric rings
- Subject: 人参 → 贾府 → 时代
- Treatment: 由内向外三级同心圆

**Text Labels**:
- Headline: "五、由家及国"
- Labels: "人参 → 贾府 → 时代", "读者诠释，非作者明示", "蔡元培：索隐派", "胡适：自传派"

## Section 6: 余响

**Key Concept**: 物之朽坏，接着人之离散。

**Content**:
- 司棋被逐，晴雯抱屈夭亡，芳官、藕官、蕊官斩情出家。
- 宝玉见阶下海棠"无故死了半边"，当作晴雯将亡的兆头。
- 蒙府本回前总批："司棋一事，前文着实写来，此却随笔收去；晴雯一事，前文不过带叙，此却竭力发挥。……"
- 庚辰本双行夹批："此等家常细事岂是揣摩得……"；"调侃语。"
- 第五回《飞鸟各投林》："好一似食尽鸟投林，落了片白茫茫大地真干净。"

**Visual Element**:
- Type: falling petals / departing figures
- Subject: 离散的人影与落花
- Treatment: 淡墨，留白

**Text Labels**:
- Headline: "六、余响"
- Labels: "司棋被逐", "晴雯夭亡", "芳官出家", "物朽，人散"

### Key Terms
- **百年人参**: 贾母"当日所余"的上等人参，因"年代太陈"而"朽糟烂木，也无性力的了"。
- **调经养荣丸**: 王夫人为病中的王熙凤所配之药，需上等人参二两。
- **脂批**: 脂砚斋等的批语；庚辰本双行夹批、蒙府本回前回末总批。
