## Main Topic

一篇以冷香丸为入口的《红楼梦》宝钗细读：药取天时、人以冷制，落点在"随分从时"。全文分"药／冷／自然"三节，余论给出四条读者解读。

## Learning Objectives

After viewing this infographic, the viewer should understand:
1. 冷香丸为什么"不能买，只能等"——四季花蕊、四节气水、皆为十二。
2. "冷"如何从药落到人身上：药香、判词、住处的雪洞。
3. "自然"的两层——药顺天时，日子也顺时候；余论的对比读法是把宝钗放在黛玉与贾敬之间看。

## Target Audience

- **Knowledge Level**: Intermediate（读过或熟知《红楼梦》情节与人物，但未必留意版本与脂批）
- **Context**: 读到该文后想要一张可保存、可转发的要点图
- **Expectations**: 一眼看懂三节结构与关键原文，不必重读全篇

## Content Type Analysis

- **Data Structure**: 三个并列母题（药／冷／自然）+ 四条独立解读（余论），母题内部是"原文—读法"对
- **Key Relationships**: 药 ← 天时；冷 ← 热毒；自然 ← 顺时；余论把宝钗与黛玉（两副药）、与贾敬（两种制药）并置，并由"任是无情也动人"引向"有情"
- **Visual Opportunities**: 四季与四节气的循环（时间感）；"十二"的重复；冷/热、顺/逆两组对立；引文可作题跋式板框
