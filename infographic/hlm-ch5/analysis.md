## Main Topic

《红楼梦》第五回的细读——贾宝玉梦游太虚幻境，翻看金陵十二钗判词、听《红楼梦》十二支曲；判词与曲把全书主要女子的结局预先写定，故第五回被称为全书"总纲"。

## Learning Objectives

After viewing this infographic, the viewer should understand:
1. 第五回为何是全书"总纲"：太虚幻境、判词、十二支曲如何预先写定结局。
2. 三个关键词：真假题眼（"假作真时真亦假"）、判词（"心比天高，身为下贱""一从二令三人木"）、十二支曲（收尾"落了片白茫茫大地真干净"）。
3. 警幻的"意淫"与迷津、脂批"点题"，以及现存末回以"假"（王一贴疗妒汤）收束。

## Key Data Points (Verbatim)

- 对联："假作真时真亦假，无为有处有还无。"
- 晴雯判词："霁月难逢，彩云易散。心比天高，身为下贱。风流灵巧招人怨，寿夭多因毁谤生，多情公子空牵念。"
- 凤姐判词："凡鸟偏从末世来，都知爱慕此生才。一从二令三人木，哭向金陵事更哀。"
- 曲收尾："好一似食尽鸟投林，落了片白茫茫大地真干净。"
- "千红一窟""万艳同杯"；脂批："隐'哭'字""隐悲字"。
- 警幻："吾所爱汝者，乃天下古今第一淫人也。"；"意淫"二字，"惟心会而不可口传，可神通而不可语达"。
- 迷津："木居士掌舵，灰侍者撑篙"。宝玉梦醒："可卿救我！"
- 脂批："点题。盖作者自云所历不过红楼一梦耳。"；"与首回中甄士隐梦景一照。"
- 甲戌本第一回眉批："能解者方有辛酸之泪，哭成此书。壬午除夕，书未成，芹为泪尽而逝。"
- 张问陶《船山诗草》诗题自注："传奇《红楼梦》八十回以后，俱兰墅所补。"
- 疗妒汤："用极好的秋梨一个，二钱冰糖，一钱陈皮，水三碗，梨熟为度。"；"人横竖是要死的，死了还妒什么！"
