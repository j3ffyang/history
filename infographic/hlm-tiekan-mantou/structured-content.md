# 红楼梦里的铁槛寺与馒头庵 — 信息图结构化内容

## Overview

两句诗做成两座寺的名字：铁槛寺对「铁门限」，馒头庵对「土馒头」。诗句出自范成大，脂批点出，正文没有明说。

## Learning Objectives

1. 两座寺名与两句诗的对应关系。
2. 诗句的作者、诗题与卷次。
3. 这是批语点出的读法，正文未明说。

## Section 2: 左半——铁槛寺

**Key Concept**: 寄灵之所，名字取自「铁门限」。

## Data Points — REFERENCE ONLY (never copy into the prompt)

### Quotes
- "所谓'铁门限'事业。" — 庚辰本双行夹批，第十二回
- "前人诗云：'纵有千年铁门限，终须一个土馒头。'是此意。故'不远'二字有文章。" — 甲戌本双行夹批，第十五回
- "原来这铁槛寺原是宁荣二公当日修造……" — 第十五回
- "寄灵于铁槛寺，日后带回原籍。" — 第十二回
- "家山随处可行楸，荷锸携壶似醉刘。纵有千年铁门限，终须一个土馒头。……" — 《石湖居士诗集》卷二十八

### Key Terms
- **铁门限**：铁门槛，喻富贵久长；寺名「铁槛」所本。
- **土馒头**：坟的俗称；庵名「馒头」所本。
- **门槛/门限**：第六十三回正文作「门槛」，脂批与诗集作「门限」。
