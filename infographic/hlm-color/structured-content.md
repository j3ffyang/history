# 由浓入素：《红楼梦》的颜色

## Overview

一张人物色谱：十三个人，十三组颜色，从贾母的软烟罗四色起笔，到末回雪影里的一领大红斗篷收束。每枚色卡只保留“姓名 + 标志色 + 一句判词”，让读者一眼看见谁浓、谁素、谁没有颜色。

## Learning Objectives

The viewer will understand:
1. 贾母如何以软烟罗四色定下全书的颜色秩序。
2. 主要人物的标志色，以及“素在外、红在里”这类内外反差。
3. “由浓入素”如何从满园大红走到雪地上的一点红。

## Section 1: 定色谱的人

**Key Concept**: 贾母不必穿得最艳，却定得下谁该艳、谁该素。

**Content**:
- 软烟罗只有四样颜色：雨过天晴、秋香色、松绿、银红；银红的又叫“霞影纱”。
- 贾母鬓发如银；第四十回赏菊，拣了一朵大红的簪于鬓上。
- 第五十回雪中：围了大斗篷，带着灰鼠暖兜，坐着小竹轿，打着青绸油伞。

**Visual Element**:
- Type: color ruler + portrait silhouette
- Subject: 一位银发老太太的侧影，鬓边一朵大红菊；身前一列四枚色票
- Treatment: 旧纸底色，细线标注四色；红与银形成第一组对比

**Text Labels**:
- `贾母`
- `银发 · 大红`
- `定色谱的人`

## Section 2: 浓艳的多色

**Key Concept**: 凤姐一身浓色相撞而不乱，是权力的外衣。

**Content**:
- 大红、石青、翡翠、豆绿，再加赤金与玫瑰。
- 第六回家常仍是桃红撒花袄、石青刻丝灰鼠披风、大红洋绉银鼠皮裙；坐褥是金心绿的闪缎。

**Visual Element**:
- Type: stacked color chips + garment silhouette
- Subject: 一件大红窄褙袄的局部，压着石青与翡翠两道色带
- Treatment: 色块饱和，边缘利落，像一块织金锦

**Text Labels**:
- `王熙凤`
- `大红 · 石青 · 翡翠`
- `浓艳的多色`

## Section 3: 半新不旧的暖调

**Key Concept**: 外面是蜜合、玫瑰紫、葱黄，里面却是一件大红袄。

**Content**:
- 蜜合色棉袄、玫瑰紫二色金银鼠比肩褂、葱黄绫棉裙，一色半新不旧。
- 这层外素内艳，正合她那“从胎里带来的一股热毒”。
- 第四十九回雪中，她穿一件莲青鹤氅。

**Visual Element**:
- Type: split garment diagram
- Subject: 外层三枚暖色小样，内层露出一角大红
- Treatment: 低饱和外层，内里一点高饱和红，形成“藏”

**Text Labels**:
- `薛宝钗`
- `蜜合 · 玫瑰紫 · 葱黄`
- `素在外，红在里`

## Section 4: 红

**Key Concept**: 宝玉的颜色，是一个字：红。

**Content**:
- 大红箭袖、银红撒花半旧大袄、厚底大红鞋；连大辫也用“红丝结束”。
- 居处与别号：怡红院、怡红公子、绛云轩。

**Visual Element**:
- Type: single-hue palette
- Subject: 一枚从正红到银红的渐变色带；旁边一枚小小的心形或玉形
- Treatment: 红为主，其余颜色仅作极小点缀

**Text Labels**:
- `贾宝玉`
- `大红 · 银红`
- `红`

## Section 5: 不写之写

**Key Concept**: 第三回通篇没写黛玉穿什么；写到的几件衣裳，偏偏都是大红。

**Content**:
- 初登场只写眉眼与神气，是留白的那一个。
- 第八回雪中罩一件大红羽缎对衿褂子；第四十九回穿大红羽纱面白狐狸里的鹤氅，束一条青金闪绿绦。
- 宝钗是素在外、红在里；黛玉是红在外、白狐在里。两人都用了红，只是一个藏，一个露。

**Visual Element**:
- Type: negative-space portrait + two-layer color card
- Subject: 一个只以眉眼线条勾出的女子轮廓，衣身处留白；旁边一枚“红面/白里”的双层色卡
- Treatment: 大量留白，红色只在衣缘与腰带上出现

**Text Labels**:
- `林黛玉`
- `红在外，青在名`
- `不写之写`

## Section 6: 雪中的跳色

**Key Concept**: 湘云一身鹅黄、大红、秋香、水红；宝琴是金翠辉煌的一点亮。

**Content**:
- 湘云：挖云鹅黄片金里大红猩猩毡昭君套；里头秋香色盘金五色绣龙短袄、水红褶子、五色宫绦。醉眠时“满头脸衣襟上皆是红香散乱”。
- 宝琴：披凫靥裘，金翠辉煌；雪中立于山坡，身后丫鬟抱一瓶红梅。

**Visual Element**:
- Type: two snow-scene vignettes
- Subject: 左：一个裹着大红昭君套、露出鹅黄与秋香内装的少女；右：一个披金翠斗篷、身后红梅瓶的少女
- Treatment: 雪地留白，人物只用色块与轮廓，不画脸

**Text Labels**:
- `史湘云`
- `鹅黄 · 大红 · 秋香`
- `色最跳`
- `薛宝琴`
- `金翠 · 红梅`
- `白雪红梅`

## Section 7: 青与无色

**Key Concept**: 满园大红里，李纨一件青，宝钗一件莲青，岫烟连避雪的外衣都没有。

**Content**:
- 从大红到莲青到青，再到没有颜色，四级台阶，一句话写完。
- 第五十一回，平儿拿了一件大红羽纱给邢岫烟。

**Visual Element**:
- Type: four-step value ladder
- Subject: 四级色阶，从大红 → 莲青 → 青 → 空白；最下一级只有一件旧衣的线描
- Treatment: 像一张褪色的织物样本条

**Text Labels**:
- `李纨`
- `青`
- `寡居的素`
- `邢岫烟`
- `无色`
- `家常旧衣`

## Section 8: 本色

**Key Concept**: 大观园里人人都在配色，只有刘姥姥不必染。

**Content**:
- 凤姐将一盘子花横三竖四的插了她一头。
- 行酒令：“中间‘三四’绿配红”，她对“大火烧了毛毛虫”；众人笑“还说你的本色”。
- 她自己也笑：“我们庄家人，不过是现成的本色。”

**Visual Element**:
- Type: earthy color chips + small mirror motif
- Subject: 土黄、赭石、灰绿的粗布色块；旁边一面小圆镜
- Treatment: 质地粗粝，与前面的丝绸色卡形成对照

**Text Labels**:
- `刘姥姥`
- `本色`
- `现成的本色`

## Section 9: 三处别调

**Key Concept**: 三个不在衣裳上立色的人：香菱的红与绿、妙玉的冷绿与艳红、夏金桂的金黄。

**Content**:
- 香菱：石榴红绫裙被泥水污了，“那裙上犹滴滴点点流下绿水来”。红裙被绿泥所污，才是她一生的底色。
- 妙玉：用自己常日吃茶的绿玉斗给宝玉斟茶；门前十数株红梅如胭脂一般。
- 夏金桂：家里单有几十顷地独种桂花，人称“桂花夏家”。

**Visual Element**:
- Type: three small specimen cards
- Subject: 一枚沾泥的红布角；一只绿玉小杯与一枝红梅；一簇金黄桂花
- Treatment: 三张卡片略小于人物主卡，像附录的标本

**Text Labels**:
- `香菱`
- `石榴红 · 泥绿`
- `红裙被绿泥所污`
- `妙玉`
- `绿玉 · 胭脂红`
- `冷绿里一点艳红`
- `夏金桂`
- `金黄`
- `桂花夏家`

## Section 10: 白茫茫

**Key Concept**: 颜色写到最后，是两场雪：一场在曲文里，一场在末回。

**Content**:
- 第五回《飞鸟各投林》：“好一似食尽鸟投林，落了片白茫茫大地真干净。”
- 第一百二十回：贾政在毗陵驿船头，看见雪影里一个人，光着头，赤着脚，披着一领大红猩猩毡的斗篷。
- 那件斗篷，与第四十九回满园姊妹一色的那种大红猩猩毡，是同一种料子。

**Visual Element**:
- Type: wide bottom band
- Subject: 大片雪白留白，中央一个极小的人影，身上一点大红
- Treatment: 极简，红点占画面不到百分之一；上方是逐渐变淡的色阶

**Text Labels**:
- `白茫茫`
- `落了片白茫茫大地真干净`
- `最后只剩雪地上一点红`

### Key Terms

- **软烟罗**：一种极轻软的罗，四色为雨过天晴、秋香色、松绿、银红。
- **霞影纱**：软烟罗中银红一色的别名。
- **猩猩毡**：红色哆罗呢一类的毛织品，并非今日的毡。
- **昭君套**：无顶的皮帽套，围在额前取暖。
- **本色**：牙牌令中既指牌色，也指庄稼人的本来面目。
