## Main Topic

一篇以颜色读《红楼梦》人物的长文：从贾母的软烟罗四色起笔，逐一辨认凤姐、宝钗、宝玉、黛玉、湘云、宝琴、李纨、岫烟、刘姥姥等人的标志色，最后以第五回“白茫茫大地真干净”与第一百二十回雪影里的一领大红斗篷收束，提出“由浓入素”的读法。

## Learning Objectives

After viewing this infographic, the viewer should understand:

1. 贾母如何以“软烟罗四色”定下全书的颜色秩序，成为“色彩的裁判”。
2. 主要人物各自的标志色，以及“素在外、红在里”这类内外反差。
3. “由浓入素”如何从第四十九回的满园大红，走到末回雪影里的一领大红斗篷。

## Target Audience

- **Knowledge Level**: 中级（读过《红楼梦》或熟悉主要人物）
- **Context**: 读完文章后想保存一张可浏览、可分享的人物色谱
- **Expectations**: 雅致、克制、有文学气，不要数据图表式的冷硬

## Content Type Analysis

- **Data Structure**: 人物 → 标志色 → 一句判词式短语；末端汇入“浓→素→白”的时间弧线
- **Key Relationships**: 贾母是定调者；宝钗与黛玉构成“藏红/露红”的反转；李纨与岫烟构成“青/无色”的降级；末回斗篷回收第四十九回的猩猩毡
- **Visual Opportunities**: 色卡/色票、人物剪影或衣饰局部、雪地与红斗篷的强对比、从密到疏的排列

## Key Data Points (Verbatim)

- “那个软烟罗只有四样颜色：一样雨过天晴，一样秋香色，一样松绿的，一样就是银红的……那银红的又叫作‘霞影纱’。”
- “全书里，贾母最像一位色彩的裁判”
- “大红（正红）、石青（近乎黑的深蓝）、翡翠（翠绿）、豆绿（浅绿）”
- “蜜合色、玫瑰紫、葱黄”
- “宝钗是素在外、红在里；黛玉是红在外、白狐在里。两人都用了红，只是一个藏，一个露。”
- “鹅黄、大红、秋香、水红，一股脑堆在一人身上”
- “从大红到莲青到青，再到没有颜色，四级台阶，一句话写完。”
- “‘本色’在这里是双关：牌面上配的是绿与红，她答的是庄稼人的日子。”
- “红裙被绿泥所污，才是她一生的底色。”
- “好一似食尽鸟投林，落了片白茫茫大地真干净。”
- “抬头忽见船头上微微的雪影里面一个人，光着头，赤着脚，身上披着一领大红猩猩毡的斗篷，向贾政倒身下拜。”
