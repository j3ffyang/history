## Main Topic
以禅宗四核心范畴——"空（Śūnyatā）、缘（Pratītyasamutpāda）、无常（Anitya）、悟道（Bodhi）"为经纬，解析曹植《洛神赋》的禅意雏形与诗性直觉，如何在曹雪芹《红楼梦》中演化为体系化、情节化的小说叙事与终极精神解脱。

## Learning Objectives
After viewing this infographic, the viewer should understand:
1. **空（Śūnyatā）**：洛神之"仿佛"、"离言说"与不可执著 ↔ 红楼梦太虚幻境、真假一体与万境归空
2. **缘（Pratītyasamutpāda）**：洛水相遇必然与分离必然 ↔ 木石前盟、因缘和合而起、散而终
3. **无常（Anitya）**："悼良会之永绝"、诸行无常 ↔ 大观园繁华生灭、盛极必衰之宿命法则
4. **悟道（Bodhi）**：洛水以心印心的瞬间默契 ↔ 宝玉历经情天后断痴出家、精神彻底解脱
5. **文脉承接**：魏晋曹植诗性直觉 → 唐宋王维、苏轼空寂静观 → 清代曹雪芹史诗完成
