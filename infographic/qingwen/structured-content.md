# 晴雯

## Overview

《红楼梦》又副册第一人。判词说她"心比天高，身为下贱"——她的一生，就是这两句的注脚：撕扇、病补雀金裘、抄检被逐、含冤夭亡，最后得宝玉一篇《芙蓉女儿诔》。

## Learning Objectives

The viewer will understand:
1. 晴雯是谁：判词、出身与性格。
2. 她的命运转折：病补雀金裘、抄检、被逐、夭亡。
3. 《芙蓉女儿诔》的核心，以及"实诔黛玉"的脂批读法。

## Section 1: 判词

**Key Concept**: 又副册第一首判词，写尽晴雯的一生。

**Content**:
- "霁月难逢，彩云易散。心比天高，身为下贱。风流灵巧招人怨，寿夭多因毁谤生，多情公子空牵念。"
- "心比天高，身为下贱"八个字；"寿夭多因毁谤生"七个字。

## Section 2: 出身

**Key Concept**: 赖大家买来 → 孝敬贾母 → 转与宝玉；不知家乡父母。

**Content**:
- 第七十七回补出：赖大家用银子买来，进府时才十岁，尚未留头。
- 贾母见她生得伶俐标致，十分喜爱，赖嬤嬤便把她孝敬贾母；后贾母又给了宝玉。
- 她不记得家乡父母，"只知有个姑舅哥哥"。

**Visual Element**:
- Type: three-step lineage
- Subject: 赖大家 → 贾母 → 宝玉（三枚小像/印章）
- Treatment: 箭头串起

**Text Labels**:
- Headline: "二、出身：两度转赠"
- Labels: "赖大家买来", "孝敬贾母", "转与宝玉"

## Section 3: 撕扇子作千金一笑

**Key Concept**: 撕扇一场，写她的娇纵与要强。

**Content**:
- 第三十一回，晴雯失手跌折扇子，当场顶撞宝玉。
- 晚间和好，宝玉说扇子"原是扇的，你要撕着玩也可以使得"，她真的撕了几把。
- 宝玉："古人云，'千金难买一笑'，几把扇子能值几何！"

**Visual Element**:
- Type: vignette
- Subject: 几把撕成两半的折扇
- Treatment: 简洁线描

**Text Labels**:
- Headline: "三、撕扇子作千金一笑"
- Labels: "千金难买一笑", "几把扇子能值几何"

## Section 4: 病补雀金裘

**Key Concept**: 最"勇"的一笔——带病补孔雀金线，挣命到深夜。

**Content**:
- 第五十一回胡庸医误用枳实、麻黄（"狼虎药"）；晴雯从幔中伸手，两根指甲"足有三寸长，尚有金凤花染的通红的痕迹"。
- 第五十二回：雀金呢褂子烧了指顶大的洞，无人敢揽。
- 晴雯："说不得，我挣命罢了。"补到自鸣钟敲过四下；"补虽补了，到底不象，我也再不能了！"

**Visual Element**:
- Type: close-up / cross-section
- Subject: 孔雀金线补洞、灯下病影
- Treatment: 特写，孔雀羽纹理

**Text Labels**:
- Headline: "四、病补雀金裘"
- Labels: "三寸长指甲", "孔雀金线", "补虽补了，到底不象"

## Section 5: 惩罚坠儿

**Key Concept**: "爆炭"脾性——戳坠儿、撵坠儿。

**Content**:
- 第五十二回，平儿虾须镯被小丫头坠儿偷去。
- 晴雯"蛾眉倒蹙，凤眼圆睁"，用一丈青向坠儿手上乱戳。
- "要这爪子作什么？拈不得针，拿不动线，只会偷嘴吃。……不如戳烂了！"

**Visual Element**:
- Type: icon / small scene
- Subject: 一丈青、针线、手
- Treatment: 冷色小景

**Text Labels**:
- Headline: "五、惩罚坠儿"

## Section 6: 抄检大观园

**Key Concept**: 硬气到底——倒箱顶撞；王夫人一句"眉眼又有些象你林妹妹"。

**Content**:
- 第七十三回傻大姐拾到绣春囊；第七十四回抄检大观园。
- 晴雯"挽着头发闯进来，豁一声将箱子掀开……朝天往地下尽情一倒"。
- 王夫人："一个水蛇腰，削肩膀，眉眼又有些象你林妹妹的。"
- 甲戌本第八回双行夹批："余谓晴有林风，袭乃钗副，真真不假。"——"晴为黛影"由此而来。

**Visual Element**:
- Type: dramatic scene
- Subject: 倒空的箱子；晴雯与黛玉的眉眼对照
- Treatment: 左右对照：晴雯/黛玉

**Text Labels**:
- Headline: "六、抄检大观园"
- Labels: "绣春囊", "眉眼像林妹妹", "晴有林风，袭乃钗副"

## Section 7: 被逐与夭亡

**Key Concept**: 被从炕上拉下撵出，含冤而终，年仅十六。

**Content**:
- 第七十七回，王夫人把她"现从炕上拉了下来"，"蓬头垢面"。
- 宝玉私探，晴雯铰下两根葱管指甲、脱下旧红绫袄与宝玉换穿。
- "我虽生的比别人略好些，并没有私情密意勾引你怎样，如何一口死咬定了我是个狐狸精！"
- 灯姑娘："谁知你两个竟还是各不相扰。可知天下委屈事也不少。"
- 宝玉梦："你们好生过罢，我从此就别过了。"

**Visual Element**:
- Type: elegy scene
- Subject: 芦席土炕、粗茶碗、葱管指甲与旧红绫袄
- Treatment: 淡墨，留白

**Text Labels**:
- Headline: "七、被逐与夭亡"
- Labels: "从炕上拉下来", "铰下指甲·互换内衣", "我从此就别过了"

## Section 8: 芙蓉女儿诔（HERO）

**Key Concept**: 《红楼梦》写给一个丫鬟的最长祭文——晴雯司芙蓉花神，诔文远师楚人，末了成了黛玉之谶。

**Content**:
- 晴雯被说成"专管这芙蓉花的"花神；宝玉："此花也须得这样一个人去司掌。"
- 宝玉撰《芙蓉女儿诔》，"前序后歌"，远师《离骚》《九辩》；"用晴雯素日所喜之冰鲛縠一幅楷字写成"。
- 序："维太平不易之元，蓉桂竞芳之月，无可奈何之日……致祭于白帝宫中抚司秋艳芙蓉女儿之前。"
- "其为质则金玉不足喻其贵，其为性则冰雪不足喻其洁，其为神则星日不足喻其精，其为貌则花月不足喻其色。"
- "高标见嫉，闺帏恨比长沙；直烈遭危，巾帼惨于羽野。"
- "自为红绡帐里，公子情深；始信黄土垄中，女儿命薄！"
- 歌末："呜呼哀哉！尚飨！"
- 第七十九回黛玉改字，定为："茜纱窗下，我本无缘；黄土垄中，卿何薄命。"黛玉"忡然变色"。
- 庚辰本双行夹批："……又当知虽诔晴雯而又实诔黛玉也。"（脂批读法）

**Visual Element**:
- Type: hero panel
- Subject: 挂在芙蓉枝上的诔文；芙蓉花；月下祭拜
- Treatment: 整幅大图，诔文微缩于纸上

**Text Labels**:
- Headline: "八、芙蓉女儿诔"
- Labels: "芙蓉花神", "前序后歌·远师楚人", "自为红绡帐里，公子情深；始信黄土垄中，女儿命薄", "茜纱窗下，我本无缘；黄土垄中，卿何薄命"

### Key Terms

- **又副册**: 金陵十二钗又副册，晴雯名列第一。
- **晴为黛影**: 由甲戌本第八回脂批"晴有林风，袭乃钗副"而来的红学读法。
- **芙蓉女儿诔**: 第七十八回宝玉为晴雯所撰祭文，前序后歌。
- **风月之谶**: 诔中"茜纱窗下，我本无缘；黄土垄中，卿何薄命"被读作黛玉之谶。
