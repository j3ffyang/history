## Main Topic

《红楼梦》又副册第一人晴雯的一生——从判词、出身，到撕扇、病补雀金裘、抄检被逐、夭亡，终于宝玉那篇最长的祭文《芙蓉女儿诔》。

## Learning Objectives

After viewing this infographic, the viewer should understand:
1. 晴雯是谁：判词（"心比天高，身为下贱"）、出身（赖大家买来→贾母→宝玉）、性格（撕扇之娇纵、罚坠儿之爆炭）。
2. 她的命运转折：病补雀金裘、抄检大观园、"眉眼又有些像你林妹妹"、被逐夭亡。
3. 《芙蓉女儿诔》的核心：晴雯司芙蓉花神、诔文远师楚人、以及"虽诔晴雯而又实诔黛玉"这一脂批/红学读法。

## Key Data Points (Verbatim)

- 判词："霁月难逢，彩云易散。心比天高，身为下贱。风流灵巧招人怨，寿夭多因毁谤生，多情公子空牵念。"
- "古人云，'千金难买一笑'，几把扇子能值几何！" — 第三十一回·宝玉
- "这只手上有两根指甲，足有三寸长，尚有金凤花染的通红的痕迹。" — 第五十一回
- "补虽补了，到底不象，我也再不能了！" — 第五十二回·晴雯
- "要这爪子作什么？拈不得针，拿不动线，只会偷嘴吃。……不如戳烂了！" — 第五十二回·晴雯
- 王夫人："一个水蛇腰，削肩膀，眉眼又有些象你林妹妹的。"
- "我虽生的比别人略好些，并没有私情密意勾引你怎样，如何一口死咬定了我是个狐狸精！" — 第七十七回·晴雯
- "谁知你两个竟还是各不相扰。可知天下委屈事也不少。" — 第七十七回·灯姑娘
- "你们好生过罢，我从此就别过了。" — 第七十七回·宝玉梦
- "此花也须得这样一个人去司掌。我就料定他那样的人必有一番事业做的。" — 第七十八回·宝玉
- 诔序："维太平不易之元，蓉桂竞芳之月，无可奈何之日……致祭于白帝宫中抚司秋艳芙蓉女儿之前。"
- 诔："其为质则金玉不足喻其贵，其为性则冰雪不足喻其洁，其为神则星日不足喻其精，其为貌则花月不足喻其色。"
- 诔："高标见嫉，闺帏恨比长沙；直烈遭危，巾帼惨于羽野。"
- 诔："自为红绡帐里，公子情深；始信黄土垄中，女儿命薄！"
- 诔："呜呼哀哉！尚飨！"
- 黛玉定稿："茜纱窗下，我本无缘；黄土垄中，卿何薄命。"
- 甲戌本第八回双行夹批："余谓晴有林风，袭乃钗副，真真不假。"
- 第七十九回庚辰本双行夹批："……又当知虽诔晴雯而又实诔黛玉也。……"
- 第七十七回庚辰本双行夹批："只此一句便是晴雯正传。可知晴雯为聪明风流所害也。一篇为晴雯写传，是哭晴雯也。非哭晴雯，乃哭风流也。"
