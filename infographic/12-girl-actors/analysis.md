## Main Topic

大观园里最容易被略过的一群人——为元妃省亲从苏州买来的十二个女戏子：她们在梨香院学戏，散入各房，最后或逐、或亡、或出家，"最能照见'人'字的分量"。

## Learning Objectives

After viewing this infographic, the viewer should understand:
1. 十二个女戏子的来历：为何而买（元妃省亲）、从哪里来（姑苏）、在哪里学戏（梨香院）。
2. 她们的名单、行当与去向，以及藕官与菂官的"假凤虚凰"、龄官"划蔷"的傲骨。
3. 她们命运的转折——遣散、逐出、出家——以及"从'戏子'到'人'"的余论。

## Target Audience

- **Knowledge Level**: Intermediate（对《红楼梦》有兴趣的读者 / 红学爱好者）
- **Context**: 读完文章后的可视化速览，或独立的一图读懂
- **Expectations**: 一眼看懂十二个小戏子是谁、做了什么、结局如何

## Content Type Analysis

- **Data Structure**: 一条命运时间线（买来→学戏→散入→逐/亡/出家）套着一份小人物册（名单·行当·去向）与两段人物细读（藕官菂官、龄官）。
- **Key Relationships**: 戏台身份 ↔ 真实情感（藕官·菂官）；"好人家的儿女" ↔ "因无能卖了"；"牢坑" ↔ 大观园；"美优伶" ↔ "千红一哭，万艳同悲"。
- **Visual Opportunities**: 十二人按行当排布的名册；藕官—菂官—蕊官三人关系；龄官划"蔷"的蔷薇花架；去留名单（各归其主）；出家归宿（水月庵/地藏庵）；脂批小笺。

## Key Data Points (Verbatim)

- "下姑苏聘请教习，采买女孩子，置办乐器行头等事。"（第十六回·贾蔷）
- "这学戏的倒比不得使唤的，他们也是好人家的儿女，因无能卖了做这事，装丑弄鬼的几年。"（第五十八回·王夫人）
- 名单：文官、宝官、玉官、龄官、芳官、藕官、菂（dì）官、葵官、豆官、艾官、茄官（菂官之后补入的蕊官）
- 行当与去向：文官—贾母留下自使；芳官—正旦，指与宝玉；蕊官—小旦，送与宝钗；藕官—小生，指与黛玉；葵官—大花面，送与湘云；豆官—小花面，送与宝琴；艾官—老外，送与探春；茄官—老旦，尤氏讨去。
- "他竟是疯傻的想头，说他自己是小生，菂官是小旦，常做夫妻，虽说是假的，每日那些曲文排场，皆是真正温存体贴之事……菂官一死，他哭的死去活来，至今不忘，所以每节烧纸。"（第五十八回·芳官）
- "比如男子丧了妻，或有必当续弦者，也必要续弦为是。便只是不把死的丢过不提，便是情深意重了。若一味因死的不续，孤守一世，妨了大节，也不是理，死者反不安了。"（第五十八回·藕官）
- "画来画去，还是个'蔷'字。再看，还是个'蔷'字……已经画了有几千个'蔷'。"（第三十回）
- "嗓子哑了。前儿娘娘传进我们去，我还没有唱呢。"（第三十六回·龄官）
- "你们家把好好的人弄了来，关在这牢坑里学这个劳什子还不算，你这会子又弄个雀儿来，也偏生干这个。"（第三十六回·龄官）
- "从此后只是各人各得眼泪罢了……自此深悟人生情缘，各有分定。"（第三十六回·宝玉）
- 敕谕"凡有爵之家，一年内不得筵宴音乐"；"各官宦家，凡养优伶男女者，一概蠲免遣发"。（第五十八回）
- "不如给他们几两银子盘费，各自去罢……咱们如今损阴坏德，而且还小器。"（第五十八回·王夫人）
- "所愿去者止四五人。"（第五十八回）
- "俏丫鬟抱屈夭风流　美优伶斩情归水月"（第七十七回回目）
- "从此芳官跟了水月庵的智通，蕊官藕官二人跟了地藏庵的圆心，各自出家去了。"（第七十七回）
- 脂批："梨香院是明写大家蓄戏不免奸淫之陋，可不慎哉，慎哉！"；"造物何当作主张，任人禀受福修长。画蔷亦自非容易，解得臣忠子也良。"；"非龄官不能如此做事，非宝玉不能如此忍……"；"四字奇想，写得纸上跳出一个女优来。"
- "千红一哭，万艳同悲"（第五回"千红一窟""万艳同杯"之谐音）
